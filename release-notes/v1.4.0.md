# Release Notes - v1.4.0

## Overview
Version `v1.4.0` introduces major UX enhancements, session management controls, and the database schema navigator.

## Key Features & Improvements
* **Modernized UI/UX Styling**: Revamped the color theme and interface layout.
* **Livy Session Configurations**: Built modal controls to manage active Livy session configurations, custom properties, and host addresses.
* **Schema Catalog Explorer**: Implemented a tree-based catalog navigator showing databases, tables, columns, and data types directly in the sidebar.
