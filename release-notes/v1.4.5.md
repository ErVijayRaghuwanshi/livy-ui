# Release Notes - v1.4.5

**Release v1.4.5 - Settings Sidebar visual upgrades, Segmented Theme Selector, Tabbed Connection Manager, and Spark/JAR dependency card grids 🚀**

Version 1.4.5 provides a complete visual and usability overhaul of the Settings Panel (`SettingsPanel.jsx`) and the Connection Manager Modal (`ConnectionModal.jsx`). This release introduces collapsible settings chevrons, dynamic session status badges, theme switcher segmented pills, a multi-tab dialog structure, latency testing tags, Spark configuration grids, and scroll boundaries.

## ✨ What's New

* **Tabbed Connection Manager Modal**: Replaced a single cluttered scrollable modal with an organized, three-tab settings area:
  1. **Livy Hosts**: Endpoint connections management, inline cancels for edits, and connectivity test indicators.
  2. **Spark Config**: Grid configurations list displaying variables as responsive key-value tags, complete with suggestions autocomplete.
  3. **JARs & Libraries**: Dependency managers listing active JAR endpoints with packages icons.
* **Chevron Rotation Transitions**: Toggling Settings sections now triggers dynamic rotate transitions on chevron icons (`rotate-90`).
* **Active Host glows & metadata**: Active Livy host lists render glowing pulse rings and host URLs in monospace formatting, with delete controls fading in on hover.
* **Active Session Dashboard**: Active sessions display within a structured, elevated card container showing clear session control buttons.
* **Dynamic Status Badges**: Added visual indicators mapping session states to tinted, border-accented pills (e.g. green for `idle`, orange pulse for `starting`, red for `dead`/`killed`).
* **Segmented Theme Control**: Upgraded the appearance theme button to a segmented pill switcher showing both Light and Dark options with active indicators.
* **About & Error Banners**: Upgraded the repository card to showcase GitHub stars and forks, and styled Axios errors into clean border-accented alert columns.
* **Responsive Modal Geometry**: Expanded connection modal width to `max-w-2xl` and enforced layout boundaries to prevent page overflows on small displays.

## 🔧 Technical Details

* Organizes connection manager modal views using an `activeTab` selection state.
* Maps session status labels to styling classes using the new `statusBadgeStyles` definition in `SettingsPanel.jsx`.
* Implements `Pencil` edit cancel hooks to reset active editing forms.
