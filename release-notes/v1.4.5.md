# Release Notes - v1.4.5

**Release v1.4.5 - Settings Panel upgrades, Tabbed Connection Modal, VS Code Preview Tabs, Monaco Scroll State Persistence, Search Jumps, and Windows Shortcut Fixes 🚀**

Version 1.4.5 provides a complete visual and usability overhaul of the Settings Panel (`SettingsPanel.jsx`) and the Connection Manager Modal (`ConnectionModal.jsx`), and bundles critical tab management, scroll persistence, and hotkey bug fixes. This release introduces collapsible settings chevrons, theme switcher segmented pills, a multi-tab dialog structure, Spark configuration grids, VS Code-style file preview tabs, Monaco view state persistence across tabs, and Windows keyboard shortcut overrides.

## ✨ What's New

* **Tabbed Connection Manager Modal**: Replaced a single cluttered scrollable modal with an organized, three-tab settings area:
  1. **Livy Hosts**: Endpoint connections management, inline cancels for edits, and connectivity test indicators.
  2. **Spark Config**: Grid configurations list displaying variables as responsive key-value tags, complete with suggestions autocomplete.
  3. **JARs & Libraries**: Dependency managers listing active JAR endpoints with packages icons.
* **Chevron Rotation Transitions**: Toggling Settings sections now triggers dynamic rotate transitions on chevron icons (`rotate-90`).
* **Active Host glows & metadata**: Active Livy host lists render glowing pulse rings and host URLs in monospace formatting, with delete controls fading in on hover.
* **Active Session Dashboard**: Active sessions display within a structured, elevated card container showing clear session control buttons.
* **Dynamic Status Badges**: Added visual indicators mapping session states to tinted, border-accented pills (e.g. green for `idle`, orange pulse for `starting`, red for `dead`/`killed`).
* **Segmented Theme Control**: Upgraded the appearance theme button to a segmented pill switcher showing both Light and Dark options with active indicators.
* **About & Error Banners**: Upgraded the repository card to showcase GitHub stars and forks, and styled Axios errors into clean border-accented alert columns.
* **Responsive Modal Geometry**: Expanded connection modal width to `max-w-2xl` and enforced layout boundaries to prevent page overflows on small displays.
* **VS Code-Style Preview Tabs**: Single-clicking a file in the File Explorer opens it in a temporary "Preview" tab (italic title). Clicking another file replaces the active preview tab, keeping tabs clean. Double-clicking or editing any preview file promotes it to a permanent tab.
* **Monaco Editor Scroll & State Persistence**: Switching between SQL file tabs now fully preserves scroll positions, cursor locations, selection ranges, and collapsed code folds instead of resetting to the top.
* **Project-wide Search & Editor Jump**: Clicking any search match in the sidebar Search panel now correctly opens the file (if closed) and centers/scrolls the Monaco editor directly onto the matched line, placing the cursor at line start.
* **Premium Custom Confirmation Overlays**: Replaced all native browser blocking confirmation dialogs (such as `window.confirm` when deleting files in the File Explorer or dropping database tables in the Schema Explorer) with cohesive, custom-designed overlay confirmation dialogs that match the visual aesthetics of the application.

## 🐛 Bug Fixes

* **Windows Command Palette Shortcut override**: Pressing `Ctrl+P` inside Monaco now correctly opens the floating Command Palette instead of launching the default Chrome browser print dialog.
* **Synchronous LocalStorage Writes**: Resolved a race condition where switching hosts showed stale sessions from the old host by performing all storage updates synchronously before state dispatches.
* **Result Panel Layout improvements**: Moved the "Hide History" toggle button inside the Run History section itself rather than on the tab bar. Set scrollbar styling in the results table to starts below header columns.

## 🔧 Technical Details

* Organizes connection manager modal views using an `activeTab` selection state.
* Maps session status labels to styling classes using the new `statusBadgeStyles` definition in `SettingsPanel.jsx`.
* Implements `viewStatesRef` and editor scroll/cursor change listeners in `SqlEditor.jsx` to cache and restore Monaco view states synchronously.
* Integrates `pendingLineReveal` flags inside `SqlFilesContext.jsx` and hooks into editor mounts to trigger line scrolls.
* Controls tab state updates (`PREVIEW_FILE`, `PROMOTE_PREVIEW_TAB`) and maps local storage caches under `livy-ui-preview-tab`.
