# Release Notes - v1.4.7

**Release v1.4.7 - Progressive Web App (PWA) Support, Dynamic Connection Health Monitoring, Nginx CORS Proxy, & Compute Resource Management 🚀**

Version 1.4.7 is a major feature update delivering PWA capabilities, real-time connection status monitoring, embedded Nginx reverse proxy for native Livy CORS support, fine-grained compute resource controls, comment-driven run history naming, and VS Code layout snapping upgrades.

---

## ✨ What's New

* **Progressive Web App (PWA) Support**:
  - Integrated `vite-plugin-pwa` with Workbox service worker asset caching.
  - Added PWA manifests and standalone app icons (`pwa-192.png`, `pwa-512.png`), enabling installation on desktop and mobile home screens.
  - Offline mode support: access and run local loopback Spark SQL queries offline when disconnected from network interfaces.

* **Connection & Server Reachability Health Monitoring**:
  - Live connection badges on Navbar displaying `Online`, `Offline`, and `Server Down` states.
  - Automated network event listeners (`online`/`offline`) and periodic API ping health checks.
  - Status Bar connection indicator pills with instant reachability status updates.

* **Embedded Nginx Reverse Proxy for Native CORS Support**:
  - Packaged standalone Nginx reverse proxy (`nginx-cors.conf`) inside the `DockerfileLivy` container image.
  - Automatically appends cross-origin resource sharing (`Access-Control-Allow-Origin`) headers and handles `OPTIONS` preflight requests on port `8998`.
  - Simplifies browser connectivity across different domains, local networks, and hosted static sites (e.g. GitHub Pages).

* **Compute Resource UI & Settings Redesign**:
  - Redesigned Connection Manager modal (`ConnectionModal.jsx`) and Settings panel (`SettingsPanel.jsx`).
  - Added preset cluster compute configurations (Small, Medium, Large, Custom) with driver/executor memory, CPU cores, and Spark submit options.
  - Tabbed configuration interface separating host endpoints, cluster sizing, and JAR/library dependencies.

* **Comment-Driven Run History Naming**:
  - Automatically extracts query titles from leading SQL comments (e.g. `-- Query: Daily Revenue Aggregation`).
  - Displays human-readable names in the Query History panel and Result Session tabs instead of raw code snippets.

* **Monaco Editor Command Palette Integration**:
  - Directly bound `Cmd+Shift+P` / `Ctrl+Shift+P` inside Monaco Editor to launch the built-in Command Palette.
  - Unified command center actions for editor formatting, file management, and host controls.

* **VS Code-Style Layout & Snap-to-Collapse**:
  - Interactive sidebar dragging with snap-to-collapse behavior when dragging below 80px width.
  - Refined corner resizer controls with dual-border hover highlights and 4-direction resize cursors.

* **Expanded Spark SQL Autocomplete & Hover Docs**:
  - Added over 100+ missing Spark SQL functions and keywords (`spark-functions-data.js`, `spark-keywords-data.js`).
  - Complete hover documentation and autocomplete triggers for modern Spark SQL operations.

* **Privacy Policy & Security Documentation**:
  - Added comprehensive `PRIVACY.md` detailing browser local storage usage, non-telemetry policy, and network security model.

---

## 🐛 Bug Fixes & Improvements

* Fixed Welcome Screen default layout state when closing all tabs.
* Resolved keyboard shortcut conflict between Monaco built-in commands and browser defaults.
* Optimized session context state updates in `LivyContext` to prevent stale reachability checks.

---

## 🔧 Technical Details

* Service worker registered via `vite-plugin-pwa` with auto-update strategy.
* `LivyContext` includes periodic `axios` health checks with 5-second timeout thresholds.
* Dual-stage Docker process execution running Livy on port `8997` and Nginx on port `8998`.
