# Release Notes - v1.4.6

**Release v1.4.6 - Monaco Undo History Preservation, Closed Tabs Retention Cache, Browser-Safe Shortcuts, and Retro Games Integration 🎮**

Version 1.4.6 introduces key editor performance and usability upgrades, including manual Monaco model swapping to preserve edit history and scroll states, a 1-hour cache for closed files, browser-safe tab switching hotkeys, and Easter egg retro game integrations.

## ✨ What's New

* **Monaco Undo History Preservation**: Switched from unmounting the Monaco Editor on tab change to a manual model-swapping architecture. Switching tabs now preserves the entire undo/redo history stack, scroll position, and cursor coordinates for each file.
* **1-Hour Closed File Cache**: Implemented a retention cache that holds closed file models for up to 1 hour. Restoring a tab (e.g. via `Cmd+Shift+T` / `Ctrl+Shift+T`) automatically restores its full edit history.
* **Browser-Safe Tab Switch Hotkeys**:
  - `Alt + ]` / `Alt + PageDown` for Next Tab
  - `Alt + [` / `Alt + PageUp` for Previous Tab
  - `Alt + 1` through `Alt + 9` to jump directly to tabs 1–9.
  *(These hotkeys bypass Chrome/Safari browser interceptions and work reliably on both macOS and Windows/Linux).*
* **Easter Egg Retro Games**: Added classic nokia snake and retro bounce games. Can be launched by running SQL commands (e.g. `play snake`, `play bounce`) or via the Command Palette.
* **Persisted Search Queries & Tabs**: Persistent search panel inputs and active sidebar tab states across page refreshes using local storage.
* **Escaped Column Names**: Escapes column names containing spaces with backticks in Schema Explorer copy/insert actions.

## 🐛 Bug Fixes

* **Monaco Action Stale Closures**: Refactored SqlEditor to use React `useRef` mappings for callback actions (like tab switches and window triggers), resolving stale closures when hotkeys are fired inside Monaco focus.

## 🔧 Technical Details

* Stores active models in `modelsRef` map and closed models in `closedModelsRef` map.
* Integrates `onSwitchToTab` callback to handle direct numerical indexing.
* Synchronizes external changes safely using content equivalence checks, ensuring cursor coordinates are not displaced during standard typing.
