# Livy UI v4.0.0 Release Notes

**Release Date:** November 26, 2026

## Highlights

### 1. Client-Side Browser Vector Memory & Opt-In Semantic Embeddings
* **Zero-Download Hybrid Retrieval**: Conversation history is indexed in IndexedDB (`livy-ui-vector-memory`) and searched via client-side BM25 combined with Turn 1 positional anchoring and the recent turn buffer.
* **Opt-In In-Browser Embeddings**: Enable `ai.semanticEmbeddings` in **Settings → AI & Copilot** to lazy-load `Xenova/all-MiniLM-L6-v2` (~23 MB) in a Web Worker for a unified 384-dim vector space across Ollama, Google Gemini, and OpenAI.

### 2. AI Copilot & Streaming Improvements
* **Native Ollama Thinking Suppression**: Switched Ollama chat to `/api/chat` with `think: false` support via `ai.ollamaThinking`.
* **Real-Time Interactive Markdown**: Responses render markdown live during streaming, with clickable **Run Query** and **Copy** buttons on SQL blocks mid-stream and non-blocking scroll when reading earlier text.
* **Direct Tools & Clean Context**: Added flat catalog tools (`list_databases`, `list_tables`, `describe_table`, `list_sessions`) for small local models, removed unsolicited table dumps from the system prompt, restored the Copilot welcome message, and cleaned up suggestion chip prompts.

### 3. Workbench UX, Feedback & Settings
* **Clean First-Time Startup**: New users land on the Welcome Screen with left sidebar, AI Copilot, and Result Table collapsed.
* **Auto-Reveal Result Table**: Running queries from the Editor, Sidebar, or AI Copilot automatically opens the Result Table.
* **Audio, Haptic & Out-of-Focus Toast Alerts**: Added Web Audio chimes and `navigator.vibrate` feedback on query completion, plus success toasts when the tab is out of focus.
* **About & History**: Added author information and release timeline under **Settings → About & History**.
