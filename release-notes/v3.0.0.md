# Release Notes - v3.0.0

**Milestone Release v3.0.0 — Dual-Engine Architecture: Apache Doris & Apache Spark SQL, Compute & Session Manager, Engine-Aware Validation, AI LLM Functions, and Modernized UI/UX 🚀**

Version 3.0.0 is a milestone release that expands Livy UI beyond Apache Spark into a universal big-data SQL workbench by introducing native, first-class support for **Apache Doris** alongside **Apache Spark SQL**.

---

## 🌟 Major Highlights & What's New

### 1. Dual-Engine Architecture (Apache Spark SQL ⇋ Apache Doris)
* **First-Class Apache Doris Integration:**
  - Execute SQL queries directly against Apache Doris Frontends using the native stateless FE HTTP Query API (`/api/query/<cluster>/<database>`).
  - No wait times for session allocation or cluster startup—Doris queries execute instantaneously.
  - Multi-database query support with dynamic catalog and schema resolution.
* **1-Click Engine Switcher:**
  - Switch between **⚡ Apache Spark SQL** and **🐬 Apache Doris** with a single click from the left Compute panel or the top Title Bar.
  - The entire editor environment (validation, autocomplete, snippets, hover documentation, status bar, and query execution) adapts reactively to the selected compute engine.

### 2. Dedicated Compute & Session Manager (`Cpu` Icon / `⌘⇧M`)
* **Segmented Engine Switcher Pill:**
  - Clean top-level switcher: `[ ⚡ Spark ]  [ 🐬 Doris ]` with amber and cyan visual accents.
* **Active Connection Card:**
  - Compact active connection summary with real-time latency ping badge (`🟢 30ms`), 1-click endpoint URL copy, and live target database dropdown (`[ demo_db ▾ ]`).
* **Saved Compute Endpoints List:**
  - Manage all Spark Livy clusters and Apache Doris endpoints with engine badges (`🐬 Doris` / `⚡ Spark`), ping status, and inline "Add Endpoint" form.
* **Doris Quick Tools (Direct Run & Insert):**
  - Instant access to cluster topology and metadata inspection:
    - 📦 **Storage Backends**: `SHOW PROC '/backends';`
    - 🖥️ **Frontend Nodes**: `SHOW PROC '/frontends';`
    - 🗄️ **Databases**: `SHOW DATABASES;`
    - 📋 **Tables**: `SHOW TABLES;`
    - 🤖 **AI Resources**: `SHOW RESOURCES;`
    - ⚡ **Workload Groups**: `SHOW WORKLOAD GROUPS;`
    - ⏱️ **Active Queries**: `SHOW PROCESSLIST;`
  - Click any tool row to insert the query into the editor, or click the **`▶ Run`** button to execute immediately and view results below.

### 3. Engine-Aware SQL Autocomplete & Documentation
* **Doris Data Types & Functions:**
  - 112+ Apache Doris built-in functions with complete signatures, usage, and examples, including native Doris AI functions (`AI_TRANSLATE`, `AI_GENERATE`, `AI_SUMMARIZE`, `AI_MASK`, `AI_EXTRACT`, etc.) and high-performance bitmap functions (`BITMAP_*`, `HLL_*`, `QUANTILE_*`).
  - 32 Doris data types: `LARGEINT`, `DATEV2`, `DATETIMEV2`, `BITMAP`, `HLL`, `QUANTILE_STATE`, `AGG_STATE`, `JSONB`, `VARIANT`, `IPV4`, `IPV6`, etc.
  - 178 Doris keywords and 13 DDL snippets (`DUPLICATE KEY`, `DISTRIBUTED BY`, Ollama/OpenAI AI resources).
* **Spark SQL Catalog Preservation:**
  - Retains all 600+ Apache Spark built-in functions, Spark ANSI keywords, and Livy boilerplate templates when Spark is active.

### 4. Engine-Aware Static SQL Validation
* **Zero False-Positive Real-Time Diagnostics:**
  - Automatically switches parser dialect based on active compute (`MySQL` for Doris, `SparkSQL` for Spark).
  - Pre-validation syntax masking normalizes Doris DDL extensions (`SHOW RESOURCES`, `SHOW PROC`, `CREATE RESOURCE`, `LARGEINT`, `DUPLICATE KEY`, `PROPERTIES`) while preserving exact character offsets, line breaks, and column numbers.
  - Genuine syntax errors (such as missing keywords or typos) are detected with exact line and column precision.

### 5. Settings Page Enhancements (`⌘,`)
* **Dedicated "Apache Doris" Category:**
  - Configure Doris Default Database, Query Timeout, Default AI Resource, Execution Profiling, and FE HTTP connectivity test ping.
* **Host Manager Upgrades:**
  - Displays engine badges (`🐬 Doris` / `⚡ Spark`) with cluster, database, username, and password fields.

### 6. Modernized UI/UX
* **Title Bar:** Added active engine badge and interactive connection chip with 1-click access to the Compute Panel.
* **Status Bar:** Dynamic target database indicator (`🐬 Doris · demo_db · Ready`).
* **Universal SQL Scratchpads:** Extensionless scratchpads (`Untitled-*`) are automatically recognized as SQL files with full autocomplete and execution support.
