# Release Notes - v2.0.0

**Milestone Release v2.0.0 - VS Code Settings Overlay, Spark Conf Manager, Real-time SQL Validation, Authentic Dark Theme, and Architecture Overhaul 🚀**

Version 2.0.0 represents a landmark milestone for Livy UI. This major release transforms Livy UI into an authentic, production-grade VS Code experience with an interactive Settings Overlay, comprehensive Spark configuration and session lifecycle management, real-time static SQL syntax diagnostics, an exact VS Code dark editor theme match, and massive performance improvements across the Result Tab and Schema Explorer.

---

## 🌟 Highlights & Major Features

### 1. VS Code Settings Overlay & Dual JSON Configuration System
* **Centered Floating Settings Overlay (`⌘,` / `Ctrl+,`):**
  - Replaces external navigation with an authentic VS Code centered overlay panel featuring unboxed configuration rows, category side navigation, and a dead-centered search bar.
  - Divided into four specialized scopes: **Editor**, **Spark & Compute**, **Livy Hosts**, and **Appearance**.
  - Blue vertical indicators denote modified settings that differ from system defaults.
  - Reset to default with safe confirmation modal dialog.
* **Dual GUI and Live Monaco JSON Editing:**
  - Integrated "Open settings (JSON)" icon in the header and inline "Edit in settings.json" shortcuts.
  - Complete two-way real-time synchronization between the visual GUI controls, the Monaco JSON editor, and browser `localStorage`.

### 2. Spark Configuration & Session Lifecycle Manager
* **Dynamic Spark Conf Manager:**
  - Visual key-value property editor supporting inline edits, additions, and deletions.
  - Common Spark properties datalist autocomplete (`spark.sql.shuffle.partitions`, `spark.driver.memory`, `spark.executor.instances`, `spark.defaultMaster`, etc.).
  - 4 one-click configuration presets: *Standard Local Mode*, *Medium Performance*, *Delta Lake Optimized*, and *Hive Warehouse Enabled*.
  - Changes instantly synchronize with active Livy session configurations and persist across sessions.
* **Integrated Compute Session Manager:**
  - Create and configure new Livy sessions directly from the Settings UI with session kind selection (`sql`, `pyspark`, `spark`), driver/executor memory, cores, and JAR dependencies.
  - Multi-pass auto-stripping for rejected static configurations (e.g., `spark.sql.extensions`, `spark.connect.*`) with an interactive "Retry without custom configs" fallback button.
  - Attach to existing active sessions, refresh live state, and kill sessions with safety confirmation modals.
* **Livy Host Management:**
  - Add, edit, remove, and ping Livy servers for reachability.
  - Click anywhere on a host card to instantly switch active servers.

### 3. Exact VS Code Dark Theme & SQL Syntax Highlighting
* **Authentic Editor Palette (`#121314`):**
  - Color-matched to VS Code's dark obsidian editor background, gutter, line numbers (`#707070`), active line highlight (`#191a1b80` / `#28292a`), and active line number (`#ffffff`).
  - Active tab card styled with `#2c2d2e` (`--color-bg-elevated`) and `#242526` border.
  - Replaced generic tab icon with the pink cylinder `Database` icon (`#ff7b72`).
* **Custom Monaco SQL Theme (`vscode-dark-custom`):**
  - **Keywords & Types** (`SELECT`, `FROM`, `WHERE`, `AND`, `AS`, `DATE`, `INNER JOIN`, `ON`, `IS NOT NULL`, `IN`, `WITH`): Coral/Salmon Red (`#ff7b72`).
  - **Built-in Functions** (`concat`, `date`, `sum`, `count`): Warm Golden Yellow (`#dcdcaa`).
  - **Strings & Backticked Paths** (`'98'`, `'2026-01-01'`, `` `hdfs://namenode/...` ``): Light Ice Blue (`#a5d6ff`).
  - **Identifiers & Columns** (`MOBILENUMBER`, `VPN_TOR`, `DATE`, `t.target_name`): Sky Blue (`#79c0ff`).
  - **Numbers**: Sky Blue (`#79c0ff`).
  - **Delimiters & Delimiter Brackets**: Light Gray (`#bcbebf`).
  - Extended Monaco's SQL Monarch tokenizer to natively recognize Spark SQL backticks (`` `...` ``) as `identifier.quote`.

### 4. Monaco Editor Enhancements & Real-time SQL Validation
* **Real-Time Static SQL Diagnostics:**
  - Integrated `dt-sql-parser` for instant SQL syntax checking as you type.
  - Displays inline red squiggly underlines and Monaco hover error tooltips with exact line and column locations.
* **File Preview Minimap:**
  - Restored editor Minimap preview on the right margin by default, with toggle options in Settings.
* **Interactive 3-Dot Sash Grip:**
  - Restored authentic vertical 3-dot sash resize handle between sidebar and editor window.
  - Persists and remains fully interactive (click to open, double-click to reset, drag to resize) even when the sidebar is collapsed.
* **Intelligent Autocomplete:**
  - Prevents autocomplete suggestions from popping up immediately after typing commas, spaces, or open parentheses.

### 5. Result Tab & Schema Explorer Performance Overhaul
* **Raw Spark Livy Inferred Values:**
  - Removed client-side value transformations; cells now preserve exact raw values returned by Spark Livy (timestamps, dates, numbers, nulls, and serialized structs/arrays).
  - CSV and JSON file downloads retain authentic unformatted values.
* **Livy Native Data Types:**
  - Column header icons and tooltips dynamically reflect exact types returned in Spark's result schema (`data.schema.fields[i].type`), supporting strings, integers, longs, floats, booleans, timestamps, dates, arrays, and structs.
* **Eliminated Schema Explorer Storm:**
  - Replaced eager recursive background pre-loading with strictly on-demand (lazy) loading when databases and tables are expanded.
  - Added in-flight deduplication guard (`inFlightRef`) and 45-second statement timeout with automatic statement cancellation to protect against session starvation.

### 6. Decoupled Backend & Modern Container Architecture
* Decoupled Spark and Livy into a dedicated `spark/` sidecar container image (`spark/Dockerfile.spark`) running Apache Spark 4.1.2 and Scala 2.13.
* Native CORS support on port 8998 via built-in `livy-next` binary (`--cors-allowed-origins "*"`).
* Switched Livy UI production web server to ultra-lightweight Caddy (`caddy:2-alpine`, ~30MB) with single-page application (SPA) routing.

## 🐛 Bug Fixes & Refinements

* **UI/UX:** Fixed TitleBar Command Center pill centering to prevent horizontal shifting when switching active Livy hosts.
* **Layout:** Restored editor Minimap and removed legacy `(...)` menu button from the editor tab bar.
* **Settings:** Resolved infinite re-render loop between `LivyContext` host updates and `SettingsContext`.
* **Resilience:** Multi-pass config stripping ensures cluster session startup succeeds even when static Spark configs or extensions are rejected by Livy.
* **Safety:** Added double-confirmation modal before resetting settings to factory defaults.

## 📦 Upgrade Guide

Livy UI v2.0.0 is fully backwards-compatible with existing `localStorage` configurations. If you are upgrading from v1.4.x:
1. Pull the latest image or codebase: `git pull origin main` or pull `livy-ui:latest`.
2. Re-build or launch with Docker Compose: `docker compose up -d --build`.
3. Open Settings (`⌘,` or `Ctrl+,`) to inspect your active host, compute configurations, and customize the editor.
