# Release Notes - v1.4.4

**Release v1.4.4 - VS Code-Style Workspace Layout, Fuzzy Command Palette, Recents Memory, and Multiple Run Sessions 🚀**

Version 1.4.4 completely transforms the Livy SQL editor's user interface to a VS Code-style layout. This release includes a persistent vertical Activity Bar, a top Title Bar with centered Command Center, a fuzzy-matching Command Palette with Recents memory, and a bottom Result Panel supporting multiple on-demand query execution sessions in a collapsible history list.

## ✨ What's New

* **VS Code-Style Title Bar & Command Center**: Replaced the top navigation bar with a slim 38px title bar containing a centered Command Center search button.
* **Persistent Left Activity Bar**: Added a 48px vertical activity bar to toggle sidebar sections (Explorer, Search, Schema, Settings). The activity bar remains visible even when the sidebar pane is collapsed.
* **Fuzzy Command Palette (`⌘P` / `Ctrl+P`)**: Created a floating command palette that matches workspace SQL files and action commands (e.g., `> Run Query`, `> Format SQL`, `> Toggle Theme`).
* **Recently Used memory**: The Command Palette now remembers up to 5 recently used actions/files, persists them in `localStorage`, prioritizes them at the top of the palette, and groups list items under styled category headers.
* **On-Demand Results Sessions**: Multiple query run results can now be managed per SQL tab. Running a query updates the active session, while clicking `+` creates a new session so you can preserve ("hold") previous results for comparison.
* **Collapsible Run History**: Renders a collapsible terminal-style "Run History" sidebar showing color-coded status badges, timestamps, and query snippets. Features a toggle clock icon in all view headers to collapse it and expand result width.
* **Settings & Host Management Section**: Migrated appearance options, Saved Livy Hosts list, and Session Attachments into a sidebar pane toggled via the Activity Bar gear icon.

## 🐛 Bug Fixes

* **Command Palette Arrow Wrap**: Resolved an issue where up/down arrows caused infinite circular scrolling.
* **List Selection Scroll Alignment**: Implemented automatic scrolling behavior to ensure keyboard-highlighted palette items scroll into view.
* **Header Spacing Alignment**: Refined layout of "Hide History" buttons inside active result headers, positioning them consistently next to maximize/close controls.

## 🔧 Technical Details

* Exposes `activeFileResultsList`, `activeResultId`, `selectResult`, `deleteResult`, `clearFileResults`, and `createResultSession` from `SqlFilesContext` to manage multiple query runs.
* Integrates `uuidv4` run keys to track statement updates inside the polling loops in `SqlEditor`.
* Manages command recents history inside `localStorage` under the `livy-ui-command-palette-recents` key.
* Persists Results Panel runs list visibility state inside `localStorage` under `livy-result-history-visible`.
