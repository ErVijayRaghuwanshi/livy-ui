# Release Notes - v1.2.0

Release v1.2.0 - Tab Isolation & Smart Result Tables ⚡️
Say goodbye to losing your query results when switching tabs! Version 1.2.0 introduces completely isolated result states for every open SQL file, plus a massive upgrade to how structured data is rendered.

✨ What's New
Per-Tab Result Tables: Every SQL tab now maintains its own isolated ResultTable. You can run a long query in Tab A, switch to Tab B to write a new query, and Tab A's results will be waiting for you when you get back.
Virtualized Data Grid: Replaced basic text outputs with a high-performance, virtualized data grid. When Spark SQL returns structured JSON data, the UI now renders a beautiful, cleanly formatted table with fixed headers and dynamic schema types that can handle massive row counts without freezing the browser.
Live Execution Timers: Added real-time clocks (LiveTimer) and ElapsedBadge indicators so you know exactly how long a Livy statement takes to execute to the millisecond.
Keyboard Shortcuts: Introduced new keyboard shortcuts to speed up your workflow (run queries directly from the keyboard without clicking the Play button).

🔧 Technical Details
Added a custom ResizeObserver and scroll-aware logic (startIdx, endIdx) to the data table to ensure only visible DOM nodes are rendered.
Mapped Livy's application/json payload directly into structured React tables, while maintaining fallback support for text/plain outputs.
