# Release Notes - v1.4.1

## Overview
Version `v1.4.1` refines the editor's Spark SQL writing assistance with schema-aware autocompletion and layout polish.

## Key Features & Improvements
* **Schema-Aware Autocomplete**: Integrated tables and columns loaded from the schema catalog directly into the editor's auto-suggestions list.
* **Platform-Aware Keyboard Mappings**: Standardized display keycap markers dynamically (e.g. `⌘` on Mac, `Ctrl` on Windows) inside placeholder guides.
* **Connection Routing**: Updated internal endpoints to use backend-proxied routing to bypass CORS issues for standard setups.
