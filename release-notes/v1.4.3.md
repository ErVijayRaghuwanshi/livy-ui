# Release Notes - v1.4.3

**Release v1.4.3 - macOS Shortcut Overrides, Welcome Screen, Restore Tab Queue & Collapsible Sidebar Sections 🚀**

A major usability and sidebar upgrade! Version 1.4.3 introduces compatibility hotfixes for macOS keyboard overrides, a custom semicolon statement parser for SQL formatting, a session-based tab restoration queue, a glassmorphic welcome screen, and a vertical stacked collapsible sidebar sections layout (Open Editors, Files, and Schema).

## ✨ What's New

* **Collapsible Sidebar Sections**: Replaced the tabbed sidebar layout with a vertically stacked, collapsible sections layout showing Open Editors, File Explorer, and Schema Explorer. Each section header supports expanded/collapsed state persistence in localStorage.
* **Open Editors Panel**: Displays a list of currently open tabs in the sidebar, highlighting the active tab, showing orange dots for dirty states, and offering hover-revealed individual close buttons. Includes a Close All action button at the header.
* **macOS Keyboard Override Compatibility**: Resolved conflicts on browser default commands (Cmd+Shift+N, Cmd+Shift+W) by remapping them to non-conflicting combinations (Cmd+Option+N, Cmd+Option+W).
* **Restore Closed Tab**: Restores the last closed tab in a session-based history queue using Cmd+Shift+T or fallback Cmd+Option+T.
* **Sleek Welcome Screen**: Created a modern, glassmorphic Welcome Screen displaying keycap commands and quick actions when all tabs are closed.
* **Statement-by-Statement SQL Formatting**: Developed a custom parser that splits SQL by semicolons (respecting comments and strings) to format and minify each statement individually without affecting the rest of the file.
* **File Search Highlights and Arrow Navigation**: File Explorer search automatically highlights the first match, supports enter-to-open, and arrow key navigation.
* **New Keyboard Shortcuts**:
  * `Cmd+Option+N` — New SQL file
  * `Cmd+Option+W` — Close active tab
  * `Cmd+Option+T` — Restore last closed tab (fallback)
  * `Cmd+Shift+T` — Restore last closed tab
  * `Cmd+Shift+K` — Focus schema search explorer (toggle)

## 🐛 Bug Fixes
* **Monaco Event Swallowing**: Monaco was swallowing global shortcut keys when focused. Added local Monaco actions mapping to the corresponding global handlers to bypass this browser/editor capture.
* **macOS Alt/Option Key Code Mapping**: Modifiers on macOS caused e.key to map to special Unicode characters (like † or ∑). Updated event listeners to evaluate e.code (e.g. KeyT) in addition to e.key to bypass symbol mapping blocks.

## 🔧 Technical Details
* `requestCloseFile()` dispatches CLOSE_FILE or triggers promptCloseFileId modal, managing close validation state in SqlFilesContext.
* `closeAllFiles()` dispatches CLOSE_ALL_FILES to close clean files and sets promptCloseFileId to trigger sequential confirmations for dirty tabs.
* `closedTabsHistory` queue stores closed tab IDs in SqlFilesContext, filtering them out on file deletion or manual reopen events.
* `expandedSections` local state in SidebarTabs reads and writes section collapse flags under the livy-sidebar-expanded-sections key in localStorage.
