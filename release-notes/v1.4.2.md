# Release Notes - v1.4.2

**Release v1.4.2 - Query History, Light Theme, Status Bar & Glyph Context Menu 🎨**

A major UX upgrade! Version 1.4.2 introduces a full query history panel, light/dark theme toggle, a VS Code-style status bar, glyph context menus for inline SQL operations, JAR file support for sessions, and a fix for the Cmd+K shortcut being swallowed by Monaco.

## ✨ What's New

* **Query History Panel**: A searchable modal (`Cmd+H`) that stores the last 50 executed queries in localStorage — with status icons (✅/❌/⚠️), elapsed time, timestamps, and file names. Click the ▶ button on any entry to re-run it instantly. Includes a search bar to filter past queries and a clear-all button.
* **Light / Dark Theme Toggle**: Added a Sun/Moon toggle in the navbar to switch between dark and light themes. The Monaco Editor theme switches in sync. Preference is persisted in localStorage.
* **Status Bar**: A new VS Code-style status bar at the bottom showing session state (with colored dot), host name, cursor position (Ln/Col), row count from the last result, and quick-access buttons for keyboard shortcuts and query history.
* **Glyph Context Menu**: Clicking the ▶ glyph in the editor gutter now opens a popup menu with three actions: Run, Format, and Minify — all scoped to that individual statement. Previously it only ran the statement directly.
* **Per-Statement Format & Minify**: Format or minify a single SQL statement without affecting the rest of the file, accessible via the glyph context menu.
* **Keyboard Shortcuts Modal**: A new modal (`Cmd+/`) displaying all available keyboard shortcuts with platform-aware labels (⌘ on Mac, Ctrl on Windows/Linux).
* **JAR File Support**: The Connection Modal now has a dedicated "JAR Files" section where you can add JAR URLs (HDFS, S3, HTTP, file://) that are sent with every new session creation. Persisted in localStorage.
* **Schema Context (Shared State)**: Introduced SchemaContext to share schema data (databases, tables, columns) across components — enabling schema-aware autocomplete in the editor that suggests table and column names from the live catalog.
* **Insert at Cursor from Schema Explorer**: Click a database, table, or column name in the Schema Explorer to insert its qualified name directly at the editor cursor position.
* **Host Delete Confirmation**: Removing a host now shows a custom confirmation dialog instead of the browser's native `window.confirm`.
* **Escape to Close**: All modals and dropdowns (connection modal, shortcuts, history, session dropdown) now close on Escape key.
* **New Keyboard Shortcuts**:
  * `Cmd+H` — Toggle query history
  * `Cmd+/` — Show keyboard shortcuts
  * `Cmd+.` — Manage Livy hosts
  * `Cmd+K` — Focus schema search

## 🐛 Bug Fixes
* **Cmd+K Intercepted by Monaco**: `Cmd+K` / `Ctrl+K` was consumed by Monaco's chord keybinding system when the editor was focused. Added a Monaco `addAction` override that routes `Cmd+K` directly to the schema search focus callback.

## 🔧 Technical Details
* `QueryHistory` component stores entries via `addHistoryEntry()` in localStorage (capped at 50), with `getHistory()` / `clearHistory()` helpers.
* Theme toggle applies a `.light` class to `document.documentElement`; Monaco uses `"light"` vs `"vs-dark"` theme strings.
* `StatusBar` reads session state from `useLivy()` and cursor position from a callback prop wired through `SqlEditor` → `App`.
* Glyph popup uses `editor.getTopForLineNumber()` for pixel-accurate positioning relative to the clicked line.
* `formatRange()` / `minifyRange()` operate on a Monaco Range scoped to a single statement's start/end lines, using `editor.executeEdits()` with undo support.
* `SchemaProvider` wraps the app, exposing databases, tables, columns state and update callbacks. `SqlEditor` reads from `useSchema()` to provide live catalog autocomplete.
* JAR files are stored via `SESSION_JARS` localStorage key and passed as `jars` in the `createSession` API call.
* Monaco `addAction` for `focus-schema-search` with `CtrlCmd | KeyK` keybinding overrides the built-in chord prefix.
