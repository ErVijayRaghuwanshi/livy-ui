# Release Notes - v1.1.1

Release v1.1.1 - Spark SQL Boilerplate Snippets 🚀
Writing Spark SQL Data Definition Language (DDL) queries just got a lot faster! Version 1.1.1 introduces smart code snippets directly into the editor's autocomplete engine, eliminating the need to memorize or copy-paste complex file-loading syntax.

✨ What's New
Smart SQL Snippets: The editor now suggests full boilerplate templates for common Spark SQL operations. Just start typing a command (like create_) and hit Enter to generate the block.
Interactive Tab Stops: Snippets are fully interactive. Once a template is inserted, you can use the Tab key on your keyboard to instantly jump between variables (like table names, file paths, and boolean options) to fill out your query in seconds.
Preloaded Templates: Added out-of-the-box support for the most common data engineering tasks:
create_view_csv: Instantly mount a .csv file with header and schema options.
create_view_json: Instantly mount a .json file.
create_table_parquet: Generate a Parquet table over HDFS/local storage.
select_limit: Scaffold a quick data exploration query.

🔧 Technical Details
Integrated CompletionItemKind.Snippet into the Monaco Editor language provider.
Snippets perfectly co-exist alongside the existing Spark SQL function and keyword hover/autocomplete providers.
